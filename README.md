Student Task Tracker

A beginner-friendly task management web application built using HTML, CSS, and JavaScript.

Features

- Add new tasks.
- Mark tasks as completed.
- Delete individual tasks.
- View total, completed, and pending tasks.
- Save tasks using browser Local Storage.
- Add tasks using the Enter key.
- Clear all completed tasks.

Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser Local Storage

Project Structure

student-task-tracker/
├── index.html
├── style.css
├── script.js
└── README.md

How to Run

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open "index.html" in your browser.

Learning Objectives

This project demonstrates basic DOM manipulation, JavaScript events, arrays, objects, functions, and browser Local Storage.
